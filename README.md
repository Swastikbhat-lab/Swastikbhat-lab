## 🚀 Shipping now

### [scrape-heal](https://github.com/Swastikbhat-lab/scrape-heal) — a scraper that repairs its own selectors

Your scraper breaks when the site redesigns. This fixes itself — or tells you exactly what broke.

<div align="center">

![scrape-heal demo](https://github.com/Swastikbhat-lab/scrape-heal/raw/main/docs/demo.gif)

</div>

Remembers what the data looked like · notices when it stops looking like that · repairs its own
selectors — but **only after proving the repair on the live page**. Watchdog mode alerts the moment a
run goes red; a selector ledger means flip-flopping sites are healed once, remembered forever.

`TypeScript · Playwright · MIT` — [repo](https://github.com/Swastikbhat-lab/scrape-heal)
